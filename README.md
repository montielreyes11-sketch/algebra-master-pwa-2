# Álgebra Master PWA

Versión mínima funcional de una PWA para seguir un plan de álgebra de 12 semanas.

## Ejecutar localmente

```bash
npx serve .
```

Abre la dirección mostrada por el servidor. La instalación PWA requiere HTTPS o `localhost`.

## Funciones

- Plan de estudio de 12 semanas
- Marcado de semanas completadas
- Barra de progreso
- Modo claro/oscuro persistente
- Persistencia con LocalStorage
- Caché básica offline mediante Service Worker
